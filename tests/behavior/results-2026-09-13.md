# Skill revision smoke test — 2026-09-13

The concrete discovery and cleanup defects are fixed and covered by executable regressions.
The agent comparison did not establish a general performance improvement or cross-model
compatibility.

## Method

Three independent Codex subagents used the same fixture generator and inherited model/settings:
no Agent Toolbox skills, the skills at `d223211`, and the revised `0.3.1` skill files in this change.
The collaboration runtime did not expose an independently verifiable deployed model ID or reasoning
setting. No model override was requested. The first task was setup; a separate follow-up repeated
setup and then requested migration, diagnosis, and a small audit. Cases after setup shared their
arm's session, so this is a smoke test rather than a fully randomized benchmark.

Agents received the realistic requests and their own raw fixtures, without the review, proposed
fixes, grading table, or other arms. Mutations were limited to disposable local fixtures; network
access, global settings, and production repositories were excluded. Each arm saved its responses
outside the target projects.

The parent independently compared file hashes, including ignored files, before setup and after
both runs, and compared both bare repositories' branch refs before and after migration. Discovery
coverage below is based on evaluator-reported reads; a separate raw tool-trace audit was not run.

| Small audit | Suggested narrow CSV clarifications; no writes | Recommended keeping the skill; included a coverage table | Recommended keeping the skill; no report table |

Across all arms, `project/AGENTS.md` was the only changed target file. Both bare remotes' branch refs
were unchanged. The agents made local tracking/remote-HEAD adjustments during migration and reported
the divergent histories as the cleanup blocker. Diagnostic and audit files remained unchanged.

The saved audit responses contained 167, 280, and 226 whitespace-separated words respectively,
including their inspection and validation notes. This measures response size only. No token, latency,
or tool-call-count comparison was recorded. The original and revised skills both handled these
particular setup and migration tasks safely; the deterministic regressions, rather than an observed
baseline agent failure, demonstrate the two original command/procedure defects.

## Other validation and limits

- All 15 repository tests passed, including the documented discovery and guarded cleanup commands.
- All four skill entrypoints passed the skill-creator validator. The three UI metadata files parsed
  successfully and retained valid skill references.
- Root `plugin.json` passed the published Agent Plugins 1.0 JSON Schema; package version is `0.3.1`.
- Git diff whitespace checks passed.

No actual client installation, GitHub default-branch/protection mutation, or multi-model comparison
was performed. The cleanup command's tests cover Git history and the exact old-tip lease; its
authorization, destination identity, default-branch, and protection preconditions still require the
skill's preceding verification. Repeat with supported clients and models before making broader
compatibility or performance claims.
